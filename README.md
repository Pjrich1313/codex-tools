# codex-tools

Repository for Codex tools and configuration for Copilot integration.

## Codex Logo

The official Codex logo (from agents.md) is included at `logos/codex.svg`.

## Usage

- Place `logos/codex.svg` in your project assets.
- Use the configuration in `config/` for Copilot coding agent setup.

## Copilot Integration

To enable Codex in GitHub Copilot:
1. Go to github.com/settings/copilot/coding_agent
2. Select allowed repositories
3. Toggle Codex under Partner agents

For Business/Enterprise, an admin must enable it at the org level.
